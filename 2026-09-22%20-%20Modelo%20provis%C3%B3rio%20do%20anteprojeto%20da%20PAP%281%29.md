Título/Tema do Projeto da Prova de Aptidão Profissional

CS-GO 2 Bomba  Eletrónica  – Réplica eletrónica interativa inspirada num jogo de computador

Desenvolvimento e construção de uma réplica eletrónica interativa inspirada no sistema de bomba presente num jogo Counter-Strike , utilizando Arduino, programação, eletrónica e uma estrutura física construída por mim.

Descrição sumária do Produto/Projeto Final

O projeto consiste no desenvolvimento de uma réplica eletrónica interativa inspirada numa bomba de um jogo, destinada a demonstrar conhecimentos de eletrónica, programação e construção de sistemas embebidos.

O equipamento será controlado por um Arduino e terá um LCD para apresentar informações, um teclado matricial para introdução de códigos, LEDs para indicar diferentes estados e um buzzer para efeitos sonoros.

O sistema terá também um interruptor vermelho de alimentação e um sistema de névoa de água controlado eletronicamente, utilizado exclusivamente como efeito visual.

O projeto será desenvolvido com componentes eletrónicos de baixa tensão e sem utilização de materiais explosivos ou pirotécnicos

Questão(ões) de investigação

Como desenvolver um sistema eletrónico interativo utilizando Arduino, capaz de controlar um temporizador, introdução de códigos, sinais luminosos e efeitos sonoros?

Como integrar diferentes componentes eletrónicos e um sistema de névoa de água numa estrutura física, garantindo um funcionamento seguro e organizado?

Estas questões estão diretamente relacionadas com o objetivo da PAP: desenvolver um sistema funcional através da aplicação prática dos conhecimentos adquiridos no curso

Problema ou problemas que irão ser abordados

O principal problema abordado neste projeto é a necessidade de desenvolver um sistema eletrónico interativo que consiga integrar diferentes componentes de hardware e software num único equipamento funcional.

Pretende-se resolver o desafio de coordenar um microcontrolador, um display, um teclado, LEDs, um buzzer, um interruptor e um sistema de névoa de água, fazendo com que todos funcionem de forma coordenada.

Outro desafio será construir uma estrutura física que permita instalar e proteger os componentes eletrónicos, mantendo uma organização adequada da cablagem e permitindo o acesso aos componentes para manutenção e testes.

Fundamentação da escolha e contributo para a comunidade escolar/empresarial

A escolha deste projeto deve-se ao interesse por tecnologia, eletrónica, programação e videojogos, permitindo transformar um conceito virtual num protótipo físico funcional.

A realização deste projeto permite aplicar conhecimentos adquiridos ao longo do curso, nomeadamente programação, eletrónica, desenvolvimento de sistemas e resolução de problemas.
